# Implementation

This folder contains the Google Colab implementation
of our Hybrid Neural Systems in Healthcare research.

## Model
CNN + LSTM Healthcare Prediction

## Technologies
- Python
- PyTorch
- CNN
- LSTM
- NumPy
- Scikit-learn
- Matplotlib

## Implementation
The CNN extracts temporal features, while the LSTM
learns sequential patterns for healthcare risk
classification using synthetic vital-sign data.

## Disclaimer
Educational prototype only. Not clinically validated.
